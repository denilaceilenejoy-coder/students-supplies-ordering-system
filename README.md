# Student Supplies Ordering System

A simple ordering page for a small school supplies shop near campus.
Built with HTML, CSS and JavaScript. No database or build step.

## Run it
1. Open this folder in VS Code (File > Open Folder).
2. Install the Live Server extension (VS Code will suggest it), then right-click `index.html` > Open with Live Server.
   You can also double-click `index.html` to open it in a browser.

## Files
- `index.html`: page structure and the five sections
- `css/style.css`: green and white styling
- `js/script.js`: products, cart, payment validation and receipt

## Sections
1. Product List  2. Shopping Cart  3. Order Summary  4. Payment  5. Receipt

Subtotal = Unit Price x Quantity. Total = sum of subtotals. Change = Amount Paid - Total.
